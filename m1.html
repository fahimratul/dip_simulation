Step 2 — Define the Kernel / Structuring Element

Click cells to toggle 0/1. The orange-bordered cell is the origin/anchor point of the kernel. If "Custom" is selected, click a cell once to set it as origin.
Default origin index (1-indexed) = floor((n+1)/2) along each dimension — e.g. n=2 → floor(1.5)=1, n=3 → floor(2)=2, n=4 → floor(2.5)=2.

Step 3 — Zero Padding

Padding is derived from the kernel size and origin so every kernel position — including at the image borders — has a full neighborhood. Padded (border) cells are shown with a hatched pattern.
