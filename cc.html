🎛️ Correlation & Convolution Simulator

Build a numeric image matrix, define a mask (kernel), zero-pad the borders, then step through Correlation and Convolution cell by cell to see how the sliding window produces each output value.

Step 1 — Define the Image Matrix

Click any cell to edit its value. Values can be any integer or decimal — background pixels are typically 0.

Step 2 — Define the Mask / Kernel

Presets:

Click a mask cell to edit its weight (integers, decimals, or negatives allowed). The orange-bordered cell is the origin/anchor. If "Custom" is selected, click a cell once to set it as origin (without editing).

Step 3 — Zero Padding

Padding is derived from the mask size and origin so every mask position — including at the image borders — has a full neighborhood. Padded cells are shown with a hatched pattern.
